# domain/ — доменная конфигурация

Знания о предметной области, вынесенные из кода: онтология, словари, единицы
измерения, правила валидации и промпты. Каталог монтируется read-only в оба
сервиса (backend — `/app/domain`, ml-extraction — `/domain`); изменения
применяются перезапуском контейнеров, без пересборки образов.

## Файлы (default/)

| Файл | Назначение | Потребитель |
| --- | --- | --- |
| `ontology.yaml` | Онтология горно-металлургического R&D (`rnd-metallurgy-v1`): типы сущностей, их свойства и примеры | ml-extraction (промпт извлечения), backend (разбор вопроса) |
| `synonyms.csv` | Канонизация терминов `canonical,alias,type`: русские и английские варианты материалов, свойств, процессов | backend (нормализация фактов и вопросов) |
| `units.yaml` | Единицы измерения: алиасы, каноническая форма, величина и множитель приведения к базовой единице | backend (сверка чисел факта с текстом источника) |
| `validation-rules.yaml` | Физические диапазоны числовых параметров: концентрации, температуры, доли | backend (проверка правдоподобия чисел) |
| `regions.yaml` | Страны и маркеры их упоминания (названия, предприятия, города); ровно одна запись помечена `domestic: true` | backend (географическая привязка утверждений и фильтр «отечественная/зарубежная практика») |
| `extraction-schema.json` | JSON Schema кандидата факта: обязательные поля, допустимые направления эффекта | ml-extraction (валидация ответа LLM) |
| `prompts/extraction.md` | Промпт извлечения: правила, схема кандидата, числовые требования; `{entity_types}`, `{relation_types}` и `{canonical_terms}` подставляются из онтологии и словаря | ml-extraction |
| `prompts/extraction_light.md` | Облегчённый промпт для простого текста без чисел | ml-extraction |

Пороги, диапазоны и словари — данные, а не код: значения читаются при старте
сервисов, изменение применяется перезапуском контейнеров.
